# 大一年度项目结题答辩 · PPT 工作目录

所有相关文件都在这个目录里：成品、素材、生成脚本、虚拟环境、预览图。

## 一分钟上手

- **要拿去讲**：`输出/RoboTwin×SmolVLA_大一年度项目结题答辩.pptx`
- **要照着讲**：`讲稿与使用说明.md`（逐页时间、口播要点、12 个问答）
- **要快速看全貌**：`输出/contact-sheet.png`（22 页缩略图）
- **要改内容**：改 `脚本/build_deck.py`，然后跑 `脚本/run.sh`

## 事实口径（改稿时务必守住）

1. 采集结果是**专家轨迹生成**，不是学习策略的成功率。
2. 5/5 与 3/5 各只有 5 次尝试，**不能**推断成功率。
3. 30 帧离线推理来自 3 条轨迹，**不是** 30 次独立试验。
4. 指令替换只证明"输出有响应"，**不证明**"模型听懂了"。
5. 6 维输出与 14 维动作**尚未对齐**，闭环没做。
