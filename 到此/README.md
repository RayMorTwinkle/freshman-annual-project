## 以后如何更新

每次安装、升级、登录、创建/停止云端实例或清理环境后，同步更新清单与计划，并在日志追加时间（Asia/Shanghai）、目的、实际命令、结果、涉及目录和遗留问题。失败也必须记录。不得把 Token、授权码、密码或完整敏感终端输出写入此目录。

本目录是人工维护的记录，不会自动监视终端或追溯未记录的历史。本次文档只保存在本地，尚未提交或推送到公开 GitHub 仓库。

- [CLI探索结论](CLI探索结论.md)：真实能力测试、限制与项目使用建议。
- `CLI实测/`：可复用脚本、测试输入、结果和导出的执行历史。
