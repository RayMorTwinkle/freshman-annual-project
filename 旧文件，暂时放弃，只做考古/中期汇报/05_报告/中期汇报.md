# 关于开展2025年度“大一年度项目计划”与“大学生科技创新项目”中期检查工作的通知
> 温馨提醒：请同学们尽快联系导师，按照通知要求完成大一年度项目计划中检相关工作，包括报告撰写、答辩PPT准备；中检答辩暂定6月中旬，具体时间、地点另行通知。相关文档可查阅群文件或通知链接下载。

为保障校区“基于项目学习”的实践教学持续顺利开展，不断完善实践教学体系，推动校区“大一年度项目计划”与“大学生科技创新项目”（简称“两个项目”）高质量发展，现决定于近期开展两个项目的中期检查工作，具体工作内容如下：

## 一、工作要求
1. **检查范围**：面向所有2025级大一年度项目计划、2025年度在研大学生科技创新项目组。
2. **组织分工与核查内容**
学院负责选派答辩专家、提供场地与组织工作（紫丁香书院协助学院组织大一年度项目），按组别开展中期检查，核查五项内容：
    1. 项目立项后已开展的主要工作
    2. 项目现阶段已取得成果
    3. 现存重难点、关键技术与疑难问题
    4. 项目有无内容变更，写明变更原因并附佐证材料
    5. 下一阶段研究方案与工作排布
3. 学院、书院负责人及指导教师须重视本次中检，依规落实各环节工作，强化过程指导，保障项目结题率与结题质量。
4. 严守学术规范：出现抄袭、剽窃、伪造数据、代写等学术不端行为，予以批评整改；屡次违规从严处置。
5. **成绩占比**：中期检查成绩按20%折算计入项目结题总成绩。

## 二、工作安排
### （一）正常在研项目
1. 专家审阅《中期检查报告》、听取项目汇报，给出整改建议与中期评分。
2. 中期不合格项目：专家组出具整改意见后可继续实施，学院督促整改并报备教务处。

### （二）申请变更/终止项目
1. 涉及组员变动、课题更名、项目终止的，负责人填报对应申请表：
    - 变更：《项目变更申请表》（附件2）
    - 终止：《项目终止实施申请表》（附件3）
2. 学院汇总答辩信息，对变更、终止项目单独备注。
3. **时限要求**：中期检查结束后不再受理任何项目变更申请。
